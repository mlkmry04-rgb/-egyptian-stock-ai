# المحلل الذكي للبورصة المصرية

واجهة Streamlit عربية لتحليل الأسهم المصرية عبر بيانات Yahoo Finance عند توفرها، وتدريب نموذج Random Forest، واختبار تاريخي بسيط.

## تشغيل محلي
```bash
pip install -r requirements.txt
streamlit run app.py
```

## النشر على Streamlit Community Cloud
1. ارفعي الملفات `app.py` و`requirements.txt` إلى مستودع GitHub.
2. افتحي https://share.streamlit.io وسجلي الدخول عبر GitHub.
3. اختاري Create app وحددي المستودع وملف `app.py`.
4. اضغطي Deploy.

## حدود مهمة
- توفر رموز الأسهم المصرية وجودة البيانات وتاريخها قد يختلف.
- البيانات ليست مضمونة أن تكون لحظية؛ التطبيق يعرض تاريخ آخر إغلاق متاح.
- نتائج التعلم الآلي والاختبار تاريخية وتعليمية وليست توصية مالية.
- لا يوجد تنفيذ تداول حقيقي في هذا التطبيق.
- قبل أي استخدام حقيقي، يلزم التحقق من جودة مصدر البيانات، ومراجعة منهجية الاختبار والتكاليف والانزلاق السعري.
