# المحلل الذكي للبورصة المصرية — النسخة المطوّرة

## التشغيل
1. ثبّت Python.
2. نفّذ: `pip install -r requirements.txt`
3. نفّذ: `streamlit run app.py`

## النشر على Streamlit Community Cloud
- ارفع `app.py` و`requirements.txt` إلى مستودع GitHub.
- اختر الملف الرئيسي `app.py`.

## ملاحظات
- رموز EGX بصيغة Yahoo Finance مثل `COMI.CA` قد لا تكون متاحة دائمًا.
- البيانات قد تكون متأخرة أو غير مكتملة.
- الإشارات والمستويات تعليمية وليست توصيات استثمارية.
- التطبيق لا ينفذ أوامر تداول.
